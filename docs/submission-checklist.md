# PayPal AI Hackathon submission checklist

Source: [official hackathon page](https://paypalaihackathon.devpost.com/). Recheck the rules page before submission.

## Project requirements

- [ ] PayPal developer platform used meaningfully in sandbox.
- [ ] AI tool/model used meaningfully; name it and explain its role.
- [ ] Working prototype or proof of concept, not only a mockup.
- [ ] Complete local run instructions or a hosted demo URL.
- [ ] Public source repository containing required source, assets, and instructions.
- [ ] Open-source license at the repository root and license selected in repository metadata.
- [ ] Text description explains the problem, audience, features, and behavior.
- [ ] Public YouTube demo under three minutes, showing the project functioning.
- [ ] Demo materials use only permitted third-party assets and music.
- [ ] Official rules reviewed and followed.

## Evidence to gather

- [ ] Record exact PayPal sandbox operations and the selected funding mode.
- [ ] Keep a redacted setup guide; never include credentials, tokens, or personal buyer data.
- [ ] State which interactions are live sandbox calls, mocks, and synthetic fixtures.
- [ ] Capture the complete successful flow and one truthful failure/recovery case.
- [ ] Confirm the hosted/local demo and setup instructions from a clean environment.

## Submission fields

- Project title and concise description
- Public repository URL
- Hosted demo URL or reproducible run guide
- AI tools and how they are used
- Public video URL
